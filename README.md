# MPB — My Personal Brag

A personal progress journal for people who build things. Record projects, learnings, milestones, experiments, and decisions.

**Keep a record of your progress.**

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Lucide icons
- localStorage persistence (no backend)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Entries stay on this device. No sync between devices or users.
- Demo data matches the Figma MVP (9 entries, 3 projects). Reset or clear from **Settings**.
- UI language: English.
